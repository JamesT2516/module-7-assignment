Module 7 Vue.js Project

Contact Me

This contact form builds on my Module 6 project. Vue.js now manages the form validation and confirmation modal using reusable components.

How the Vue Form Works

Vue.js uses reactive data to check each field while you type. The name must contain letters and spaces, the email must be valid, and the message must contain at least 10 characters.

Error messages appear directly below the relevant fields using Vue's v-if directive. The form only becomes ready for submission when all three fields are valid.

Once submitted, a separate Vue component displays the entered information in a confirmation modal.

This is a course project. Information entered into this form is not sent to a server.

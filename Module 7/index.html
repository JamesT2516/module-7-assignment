My Journey

About Me

I am building my front-end development skills one module at a time and using this portfolio to apply what I learn in a practical way.

Learning Through Practice

Hi, I’m James Taljaard. I’m currently completing a Front-end Web Development course and developing this portfolio alongside the course.

I started by learning how semantic HTML gives a webpage structure and meaning. I then introduced CSS to work with colour, typography, spacing, layout, and the overall appearance of a site.

From Static Pages to Interaction

As the course progressed, I moved into responsive design using a mobile-first approach, media queries, Flexbox, and CSS Grid.

JavaScript has added another layer to that learning. Instead of only designing how a page looks, I am learning how a webpage can listen for user actions, make decisions, update content, and provide useful feedback.

My Current Focus

Module 6 is helping me develop a deeper understanding of DOM manipulation, event handling, form validation, and interactive user interfaces.

I am also being introduced to asynchronous JavaScript, API integration, modern JavaScript development tools, and the foundations of Vue.js.

What I Am Learning

I am now moving beyond basic JavaScript and learning how it can be used to create more useful, responsive, and interactive web experiences.

DOM Manipulation

I am learning how JavaScript works with the Document Object Model to find elements and update webpage content without reloading the page.

  • querySelector and querySelectorAll
  • Changing text and attributes
  • Adding and removing elements
  • Working with classList

Events and User Interaction

I am learning how event listeners allow a webpage to respond to actions such as clicking, typing, submitting forms, and pressing keys.

  • addEventListener
  • Click and input events
  • Submit and keydown events
  • Event bubbling and delegation

Validation and Feedback

For Assignment 6, I am applying JavaScript to validate user input while it is entered and provide useful feedback immediately.

  • Checking user input
  • Conditional validation
  • Real-time error messages
  • Confirmation modal interaction

Asynchronous JavaScript

Module 6 is introducing me to how JavaScript can manage tasks that take time without stopping the rest of a webpage from continuing to work.

  • Callbacks
  • Promises
  • Async and await
  • Fetching data from APIs

Debugging and Modern Tools

I am using browser developer tools to inspect and debug JavaScript more effectively and understand what is happening while my code runs.

  • Console testing
  • Breakpoints
  • Watching variable values
  • Network request inspection
  • JavaScript modules and bundlers

Vue.js Foundations

I am being introduced to Vue.js and how a JavaScript framework can make interactive interfaces easier to organise and reuse.

  • Reactive data
  • Templates
  • Directives
  • Reusable components
  • Props

About Me

I am building my front-end development skills one module at a time and using this portfolio to apply what I learn in a practical way.

Learning Through Practice

Hi, I'm James Taljaard. I'm currently completing a Front-end Web Development course and developing this portfolio alongside the course.

I started by learning how semantic HTML gives a webpage structure and meaning. I then introduced CSS to work with colour, typography, spacing, layout, and the overall appearance of a site.

From Static Pages to Interaction

As the course progressed, I moved into responsive design using a mobile-first approach, media queries, Flexbox, and CSS Grid.

JavaScript has added another layer to that learning. Instead of only designing how a page looks, I am learning how a webpage can listen for user actions, make decisions, update content, and provide useful feedback.

My Current Focus

In Module 7, I am learning how Vue.js can simplify the development of interactive websites through reusable components and reactive data.

I am applying these concepts by upgrading my Module 6 contact form using Vue 3. The new version includes v-model for reactive inputs, computed properties for real-time validation, v-if for displaying error messages, and props and component events for communication.

What I Am Learning

In Module 7, I am learning how Vue.js makes it easier to build interactive websites using reusable components, reactive data, and dynamic user interfaces.

DOM Manipulation

I have learned how JavaScript works with the Document Object Model to find elements and update webpage content without reloading the page.

  • querySelector and querySelectorAll
  • Changing text and attributes
  • Adding and removing elements
  • Working with classList

Events and User Interaction

I have learned how JavaScript event listeners allow a webpage to respond to actions such as clicking, typing, submitting forms, and pressing keys.

  • addEventListener
  • Click and input events
  • Submit and keydown events
  • Event bubbling and delegation

Validation and Feedback

In Module 6, I developed a JavaScript contact form that validated user input as it was entered and provided immediate visual feedback.

  • Checking user input
  • Conditional validation
  • Real-time error messages
  • Confirmation modal interaction

Asynchronous JavaScript

Module 6 introduced me to how JavaScript can manage tasks that take time without preventing the rest of a webpage from continuing to work.

  • Callbacks
  • Promises
  • Async and await
  • Fetching data from APIs

Debugging and Modern Tools

I am using browser developer tools to inspect and debug JavaScript, identify errors, and understand what is happening while my code runs.

Module 6 Contact Form

In Module 6, I developed a dedicated contact page with JavaScript-powered real-time validation.

The form checked a visitor's name, email, and message while they typed. Once every field was valid, JavaScript prevented normal form submission and displayed the information in a confirmation modal.

04

Module 7 Vue.js Contact Form

For Assignment 7, I upgraded my JavaScript contact form to use Vue 3 and reusable components.

The form uses v-model to manage reactive input values, computed properties for real-time validation, and v-if to display error messages.

Props allow the form labels and placeholders to be customised. Validated information is passed to a separate confirmation modal using component events.
